취약도함수Fragility functions — probability of exceeding a damage state

취약도함수는 «이 정도로 흔들리면 이 구조물이 이만큼 손상될 확률» 하나를 나타내는 곡선입니다. 확정적인 안전 판정 대신 확률을 쓰는 이유는, 같은 IM 값에서도 손상 결과가 갈리기 때문입니다. A fragility function gives the probability that a structure exceeds a damage state at a given level of shaking — probability, because the same IM does not always produce the same outcome.

정의Definition

P( DS ≥ dsi | IM = x )  =  Φ ( ln( x / θi ) / βi )

Φ 표준정규 누적분포함수 · θᵢ 손상상태 i의 중앙값(median IM) · βᵢ 대수표준편차(logarithmic standard deviation).

즉 취약도함수는 «손상상태 i에 도달하게 만드는 IM»이 대수정규분포를 따른다고 보고, 그 누적분포를 그린 것입니다. θ는 곡선의 좌우 위치(강한 구조일수록 오른쪽), β는 곡선의 완만함(불확실성이 클수록 눕습니다)을 결정합니다. The IM that causes damage state i is treated as lognormal; θ shifts the curve, β flattens it.

손상상태Damage states

손상상태는 임의로 정하는 것이 아니라, 관측 가능한 물리적 기준으로 정의해야 재현성이 생깁니다. 흔히 쓰는 4단계 구분은 다음과 같습니다.

  • DS1 경미 slight — 미세균열. 기능 유지.
  • DS2 중간 moderate — 부재 균열 확대, 부분 보수 필요.
  • DS3 심각 extensive — 주요 부재 손상, 사용 중단.
  • DS4 완전 complete — 붕괴 또는 복구 불가.

손상상태는 서로 배타적이지 않고 «초과» 개념이므로, 곡선은 항상 DS1 ≥ DS2 ≥ DS3 ≥ DS4 순서로 위에 놓입니다. Because the curves are exceedance probabilities, they must nest in that order.

어떻게 만드는가How they are built

  • 해석적 analytical — 지진기록 세트를 점증적으로 키우며 비선형 동적해석을 반복하고(IDA), 각 기록이 손상상태를 넘긴 IM을 모아 대수정규분포를 적합합니다.
  • 경험적 empirical — 실제 지진 후 조사된 IM–DS 쌍을 회귀합니다. 표본이 지역·구조형식에 묶이는 한계가 있습니다.
  • 전문가 판단 judgemental — 자료가 없을 때 쓰며, β가 크게 잡힙니다.

적합 방법 · Fitting

IDA 결과에서 각 기록의 붕괴 IM을 얻었다면, θ와 β는 그 값들의 로그 평균·로그 표준편차로 추정할 수 있습니다.

ln θ̂  =  ( 1 / n ) Σ ln IMj     β̂  =  √[ ( 1 / ( n − 1 ) ) Σ ( ln IMj − ln θ̂ )² ]

IMⱼ는 j번째 지진기록이 해당 손상상태를 유발한 IM 값, n은 기록 수입니다. 자료가 절단(censored)된 경우에는 최대우도추정을 써야 합니다 — Baker (2015).

이 사이트에서의 쓰임Use in this record

기록된 사건에서 «관측된 IM»과 «조사된 DS»가 함께 확보되면 그 쌍(IM–DS pair)을 데이터베이스에 넣습니다. 다만 정식 조사보고서로 DS가 확정되기 전에는 넣지 않습니다 — 준실시간 피해 집계는 DS 판정의 근거가 될 수 없기 때문입니다. An IM–DS pair enters the database only once a formal report fixes the damage state; provisional damage counts cannot establish DS.

취약도함수 — 주어진 IM에서 특정 손상상태를 초과할 확률을 주는 함수 (fragility function).
손상상태 — 관측 기준으로 정의된 구조물의 손상 단계 (damage state, DS).
대수정규분포 — 로그를 취하면 정규분포가 되는 분포 (lognormal distribution).
θ — 해당 손상상태의 중앙값 IM (median capacity).
β — 로그 축에서의 산포 (logarithmic standard deviation, dispersion).
IDA — 지진기록의 세기를 단계적으로 키우며 반복 수행하는 비선형 동적해석 (incremental dynamic analysis).
